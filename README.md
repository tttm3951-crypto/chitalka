# 📖 Читалка

Программа для Windows: читает книги вслух и делает из них **аудио рассказы в MP3** для телефона.
Можно загрузить книгу или PDF прямо с телефона — компьютер озвучит её сам.

## Установка одним кликом

1. Скачайте **[Chitalka-Setup.exe](https://github.com/tttm3951-crypto/chitalka/raw/main/setup/Chitalka-Setup.exe)**.
2. Запустите, отметьте нужные улучшения и нажмите «Установить».
   Установщик сам скачает Python (если его нет), программу, голоса и создаст ярлык «Читалка».
   Права администратора не нужны.

> Windows SmartScreen может предупредить о «неизвестном издателе»: нажмите «Подробнее» → «Выполнить в любом случае».

Без установщика: скачайте архив (Code → Download ZIP), распакуйте и запустите `install.bat`.

## Что умеет

- PDF, EPUB, FB2, DOCX, TXT, RTF, MOBI, DJVU; сканы распознаёт (OCR Windows).
- Онлайн-голоса Microsoft и офлайн-голоса Piper и Silero; голоса-копии по образцу записи (XTTS v2).
- Ударения, словарь произношения, сокращения и числа читаются правильно, сноски и библиография пропускаются.
- Разные голоса для автора, героев, героинь и детей.
- Сохранение в MP3 с главами и обложкой одним файлом, M4B, версии ×1.2 / ×1.5, фон (дождь, камин).
- Очередь книг, пауза и продолжение, горячая папка, отправка готовых книг в Telegram.

## Улучшения на выбор

| Компонент | Размер | Зачем |
|---|---|---|
| Офлайн-голоса Piper (русские) | ≈ 250 МБ | читать без интернета |
| Голоса Silero | ≈ 2,7 ГБ с NVIDIA / ≈ 300 МБ без | самые живые русские офлайн-голоса |
| M4B и ускоренные версии | ≈ 35 МБ | ffmpeg |
| Распознавание сканов | ≈ 5 МБ | OCR Windows |
| Доступ с телефона из интернета | ≈ 60 МБ | туннель Cloudflare |
| Piper: казахский, английский, украинский | ≈ 330 МБ | книги на других языках |
| Голоса-копии XTTS v2 | ≈ 2,5 ГБ | голос по образцу записи |

Доустановить потом: **Справка → 🧩 Компоненты и улучшения**.

## Обновления

Читалка раз в день проверяет новую версию и предлагает обновиться (**Справка → 🔄 Проверить обновления**).
Настройки, голоса, закладки и очередь при обновлении не трогаются; прежние файлы программы
сохраняются в папке `backup`.

## С телефона

**Файл → 📱 Доступ с телефона**: включите доступ, откройте ссылку на телефоне (или наведите камеру на QR-код),
введите PIN. Загрузите книгу или PDF, выберите голос — и нажмите «Создать аудио рассказ».
Готовый MP3 можно послушать и скачать на той же странице.

- **Дома** — ссылка по Wi-Fi (телефон и компьютер в одной сети).
- **Из интернета** — защищённая ссылка `https://….trycloudflare.com` (компонент «Доступ с телефона из интернета»).
  Без PIN по ней ничего не открыть; после 5 неверных PIN вход закрывается на 10 минут.

Подробная инструкция — в файле [Инструкция.md](Инструкция.md).
